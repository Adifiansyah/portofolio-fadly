# Portofolio Alief Fadly Adifiansyah

Website ini dibuat menggunakan HTML, CSS, dan JavaScript berdasarkan CV yang diberikan.

## File
- `index.html`: konten halaman.
- `style.css`: stylesheet.
- `script.js`: tahun footer otomatis.

## Menjalankan
Ekstrak ZIP lalu buka `index.html` di browser. Untuk mengedit, buka folder di Visual Studio Code.

## Publikasi dengan GitHub Pages
1. Buat repositori Public di GitHub, misalnya `portfolio-alief`.
2. Unggah `index.html`, `style.css`, dan `script.js` ke direktori utama repositori.
3. Buka Settings → Pages.
4. Pilih `Deploy from a branch`, branch `main`, folder `/(root)`, lalu Save.
5. Setelah deployment selesai, alamat biasanya `https://USERNAME.github.io/portfolio-alief/`.

Periksa kembali informasi kontak sebelum membuat website publik. Konten proyek dan pengalaman disusun dari CV; detail hasil proyek dapat ditambahkan hanya jika sesuai dokumentasi asli.
